## 1. 목적

Shorts 주장의 **맞는 절반**(대형 자금은 시장가 일괄 체결이 어려워 주문을 쪼갠다)을  
**틀린 절반**(그걸 따라 사면 쉽게 번다 / 특정 인물 1800억 신화)과 분리한다.

앱에서는 **관찰·알림 플래그**만 둔다.

| 한다 | 안 한다 |
|------|---------|
| `ALERT_SLICE_BAND` 연구 플래그 | Enter 강제 / 비중 자동 상향 |
| 대시보드·알림 우선순위에 “수급 관찰” 태그 | Paper/Live ON |
| 이후 백테스트·정밀도 측정용 로그 | 종목 매수 권유 문구 |

## 2. 가설 (검증 대상)

**H1.** 유동성이 충분한 종목에서, **좁은 가격 밴드** 안에서 **N거래일 연속** 매수 우세(또는 기관/외국인 순매수)가 관측되면,  
이후 단기(5~20일) 상승 확률이 랜덤보다 높다.

**H0.** 해당 패턴은 승률·기대값이 동전 던지기 수준이거나, 거짓양성(분배·실패매집·스푸핑성 잔량)이 많아 알림만으로도 노이즈다.

→ H0가 기각될 때까지 **Enter 비트로 승격하지 않음.**

## 4. 정의 (v0 탐지 규칙 — 구현 전 스펙)

### 4.1 가격 밴드

- Lookback 창: 최근 `W = 5` 거래일 (Shorts “며칠”의 최소 해석)
- 밴드 폭: `(high_W − low_W) / close_last ≤ β`
  - 기본 `β = 0.04` (4%) — 횡보 스캔 6%보다 타이트
- 종가가 밴드 중앙 근처: optional `|close − mid| / mid ≤ 0.015`

### 4.2 “매수 집중” 프록시 (데이터 계층)

**Tier A (선호, KRX 투자자별 매매)**  
일별 `기관순매수 > 0` 또는 `외국인순매수 > 0` 이 `K ≥ 3`일 / `W`일 중.

**Tier B (대체, 체결·거래량만)**  
- 일별 `close ≥ open` 일수 ≥ `K`  
- 창 평균 대비 거래량 `ADV_W / ADV_60 ≥ 1.2`  
- (가능하면) 종가 부근 매수 잔량 우세 — 없으면 생략

**Tier C (약함, 사용 시 severity=watch 고정)**  
가격 밴드만 충족 + 거래량 중립.

### 4.3 플래그 점화

```
ALERT_SLICE_BAND = 1
  iff bandOK
 and (TierA_ok OR TierB_ok)
 and not hardExclude
```

`hardExclude` 예:
- 일중 급등 `≥ +8%` (추격)
- 관리종목·거래정지·시총/ADV 하한 미달 (`C_liq_dry`와 동일 임계 재사용)
- MOS `KR_RETAIL` 등 δ*=null 섹터는 플래그는 가능하나 UI에 “자동진입 섹터 아님” 표기

### 4.4 기본 파라미터 (잠금 전 초안)

| 심볼 | 값 | 의미 |
|------|-----|------|
| W | 5 | 횡보·분할 관측 창 |
| β | 0.04 | 밴드 폭 |
| K | 3 | 매수 우세 최소 일수 |
| ADV boost | 1.2 | Tier B 거래량 |
| minADV KR large | RESEARCH.liq 와 동일 | 유동성 |

파라미터는 **스펙 잠금 전**이며, 백테스트 후 조정.

## 6. 거짓양성 / 리스크

1. **분배(distribution):** 고점에서 동일 밴드 매도 분산을 매수로 오인  
2. **실패 매집:** 밴드 이탈 하방 시 손절 없는 “따라사기” 파산 경로 (Shorts의 핵심 해악)  
3. **이벤트 대기:** 실적·락업·지수 편입 전 호가 왜곡  
4. **서머/연휴 유동성:** 밴드가 쉽게 좁아짐 → 노이즈 증가  
5. **마케팅 오염:** Shorts 수익 신화와 플래그를 UI에서 분리 (인물명·수익액 인용 금지)
